
# FULL STACK CRUD APPLICATION-FRONTEND


## 🎨 Frontend Overview

This project frontend is built with **React.js**, **Bootstrap 5**, and **Axios** to create a **fully interactive CRUD application**. Here's what it does:

### 🏠 Pages

* **Home Page** 🖥️
  Displays all users in a **responsive table**.
  Features:

  * View user details 🔍
  * Edit user ✏️
  * Delete user ❌
  * Navigate to add user page ➕

* **Add User Page** ➕
  A **form** to add a new user.
  Features:

  * Enter name, username, and email ✍️
  * Submit form to backend ✅
  * Cancel and return to home page ❌

* **Edit User Page** ✏️
  A **form pre-filled with existing user data**.
  Features:

  * Update user details 📝
  * Submit changes to backend ✅
  * Cancel and return to home page ❌

* **View User Page** 🔍
  Shows **user details in a card layout**.
  Features:

  * View full name, username, and email 📋
  * Navigate back to home page ⬅️

---

### ⚡ Features

* **Responsive Navbar** 🌐

  * Links to Home and Add User pages
  * Mobile-friendly hamburger menu

* **Interactive Buttons** 🔘

  * Add, Edit, View, Delete user actions
  * Styled with **Bootstrap 5**

* **Axios Integration** 🌊

  * Connects frontend to backend APIs
  * Handles GET, POST, PUT, DELETE requests

* **React Router** 🛣️

  * Smooth navigation between pages
  * URL parameters for edit/view actions

---

### 💡 How It Works

1. User visits **Home** 🏠 → Table loads all users from backend via Axios.
2. User clicks **View** 🔍 → Goes to **View User** page to see details.
3. User clicks **Edit** ✏️ → Goes to **Edit User** page to update info.
4. User clicks **Delete** ❌ → User removed from backend and table updated.
5. User clicks **Add User** ➕ → Goes to **Add User** page to create a new user.
